# DRAGON LOCK – Digital Life Green

**Cosmic Secure Liquidity Locker for Monad Blockchain**

---

## 🌟 Overview

**DRAGON LOCK** is a digital, green, cosmic-themed liquidity locker for the Monad blockchain.  
It allows users to lock their tokens securely, view lock status, and interact with a real-time dashboard and DEX Screener.

---

## 🚀 Features

- **Connect Wallet**  
  Securely connect your MetaMask wallet to interact with the locker.

- **Total Locks Display**  
  See the total number of locks on the platform in real time.

- **Life Time Days**  
  Displays the lock period (e.g., 180 days) in a digital green style.

- **Life Time Price**  
  Shows the lock fee (e.g., 0.01 MON) in a digital, readable format.

- **Your Locks Dashboard**  
  - View all your token locks with status: Locked, Unlocked, Withdrawn
  - See token address, amount, lock/unlock dates, and optional description
  - Real-time digital timer for each lock (days, hours, minutes, seconds)
  - Progress bar for each lock
  - Withdraw button for unlocked tokens

- **LIFE TIME DEX SCREEN**  
  - Embedded [DEX Screener](https://dexscreener.com/monad/0x1b685B0c771b877d1a4e8F02365a4A809E962c81) for your token pair
  - Black, readable dashboard with green cosmic highlights

- **Contract Link**  
  - [View contract on MonadVision](https://monadvision.com/address/0x866a16c42F6B0016E048aCd696662bE2E7d31F5F?tab=Contract)

## 🖥️ Main Functions

- **Connect Wallet:**  
  `Connect` button triggers MetaMask connection and loads your locks.

- **Load Stats:**  
  Fetches and displays total locks, lock period, and lock fee.

- **Load Locks:**  
  Fetches all locks for the connected wallet and displays them in a dashboard.

- **Display Lock:**  
  For each lock:
  - Shows lock ID, status, token, amount, lock/unlock dates, description
  - Shows a real-time countdown timer
  - Shows a progress bar
  - Enables withdrawal if unlocked

- **Start Timer:**  
  Updates the countdown timer for each lock every second.

- **Withdraw Lock:**  
  Allows withdrawal of tokens after the lock period ends.

- **Format Amount/Date:**  
  Helper functions to display token amounts and dates in a readable format.

- **Show Error:**  
  Displays error messages in a styled alert.
